Coding Decoding

কোডিং ডিকোডিং

ভূমিকা ও সংজ্ঞা (Introduction & Definition)

Coding Decoding (কোডিং ডিকোডিং) হল একটি নির্দিষ্ট নিয়ম অনুসরণ করে অক্ষর বা শব্দকে কোড ভাষায় লেখা এবং কোড থেকে মূল শব্দ খুঁজে বের করা। ANM GNM পরীক্ষায় Letter Coding, Number Coding এবং Symbol Coding — এই তিন ধরনের প্রশ্ন আসে।

Coding (কোডিং): একটি নিয়ম অনুসারে শব্দ বা অক্ষরকে অন্য একটি রূপে (কোড) পরিবর্তন করা। যেমন: CAT কে DBU লেখা (প্রতিটি অক্ষর +1)। 💡 MCQ Tip: প্রতিটি অক্ষরের পরিবর্তন আলাদা ভাবে চেক করুন
Decoding (ডিকোডিং): কোড ভাষা থেকে মূল শব্দ বা অক্ষর খুঁজে বের করা। Coding-এর বিপরীত প্রক্রিয়া। 💡 MCQ Tip: Coding নিয়ম বুঝে Reverse করলেই Decoding হয়ে যায়
Caesar Cipher (সিজার সাইফার): প্রতিটি অক্ষরকে একটি নির্দিষ্ট সংখ্যায় সরিয়ে কোড তৈরি করা। যেমন: +1 মানে A→B, B→C, C→D। +2 মানে A→C, B→D। 💡 MCQ Tip: প্রথম ও শেষ অক্ষরের shift চেক করুন
  • তিন প্রকার: Letter Coding, Number Coding, Symbol Coding
  • Letter Coding: অক্ষর → অন্য অক্ষর (shift/replace)
  • Number Coding: অক্ষর → সংখ্যা (Position Value)
  • Symbol Coding: অক্ষর → চিহ্ন (@, #, $, %, & ইত্যাদি)
  • Reverse Coding: শব্দের অক্ষর উল্টো করে লেখা
  • Mixed Coding: একাধিক নিয়ম একসাথে প্রয়োগ

গুরুত্বপূর্ণ নিয়ম ও ধরন (Important Rules & Patterns)

কোডিং ধরন (Type) নিয়ম (Rule) উদাহরণ (Example)
+1 Shift প্রতিটি অক্ষর 1 ঘর এগিয়ে CAT → DBU
+2 Shift প্রতিটি অক্ষর 2 ঘর এগিয়ে CAT → ECV
-1 Shift প্রতিটি অক্ষর 1 ঘর পিছিয়ে CAT → BZS
Opposite Letter প্রতিটি অক্ষর বিপরীত CAT → XZG (C↔X, A↔Z, T↔G)
Reverse Order শব্দ উল্টো করে লেখা CAT → TAC
Number Code Position Value ব্যবহার CAT → 3-1-20
Variable Shift প্রতিটি অক্ষরে ভিন্ন shift CAT → D(+1) C(+2) W(+3)
Condition Based শর্ত অনুযায়ী ভিন্ন কোড Vowel → # , Consonant → @ 
        Letter Coding Table (+1 Shift):
        
        Original: A  B  C  D  E  F  G  H  I  J  K  L  M
        Code:     B  C  D  E  F  G  H  I  J  K  L  M  N
        
        Original: N  O  P  Q  R  S  T  U  V  W  X  Y  Z
        Code:     O  P  Q  R  S  T  U  V  W  X  Y  Z  A
        
        Example: CAT → D(C+1) B(A+1) U(T+1) = DBU
⚡ শর্টকাট ট্রিক (Shortcut Trick): প্রথম অক্ষর এবং কোডের প্রথম অক্ষরের পার্থক্য বের করুন। যদি CAT → DBU হয়, তাহলে C→D = +1। সব অক্ষরে একই shift কিনা চেক করুন। একই হলে সব অক্ষরে সেই shift প্রয়োগ করুন।

সবিস্তার উদাহরণ (Solved Examples)

📝 উদাহরণ ১ (Example 1): যদি CAT কে DBU লেখা হয়, তাহলে DOG কে কী লেখা হবে?
(A) EPH (B) FQI (C) EPG (D) DPH
পদক্ষেপ (Steps):
Step 1: কোডিং নিয়ম বের করুন: C→D(+1), A→B(+1), T→U(+1)
Step 2: নিয়ম: প্রতিটি অক্ষর +1 shift
Step 3: DOG → D+1=E, O+1=P, G+1=H = EPH
∴ উত্তর (Answer): Option (A) EPH
📝 উদাহরণ ২ (Example 2): যদি COME কে XLNV লেখা হয়, তাহলে GONE কে কী লেখা হবে?
(A) TLMV (B) TLNV (C) TPMV (D) TMOV
পদক্ষেপ (Steps):
Step 1: C↔X (3+24=27), O↔L (15+12=27), M↔N (13+14=27), E↔V (5+22=27)
Step 2: নিয়ম: Opposite Letter (যোগফল 27)
Step 3: G↔T(7+20=27), O↔L, N↔M, E↔V → GONE = TLMV
∴ উত্তর (Answer): Option (A) TLMV
📝 উদাহরণ ৩ (Example 3): যদি PEN কে 16-5-14 লেখা হয়, তাহলে 2-1-7 কোন শব্দ?

গুরুত্বপূর্ণ তথ্য (Important Facts)

  • সবচেয়ে কমন: +1, +2, -1, -2 Shift Coding পরীক্ষায় সবচেয়ে বেশি আসে
  • Opposite Letter: Forward + Reverse Position = 27 সবসময়
  • Reverse Coding: শব্দ উল্টো করা — সহজ কিন্তু ভুল হতে পারে, সাবধান
  • Number Coding: Position Value (A=1, B=2...) মনে রাখুন
  • Variable Shift: প্রতিটি অক্ষরে আলাদা shift হতে পারে
  • Symbol Coding: Table দিয়ে দেওয়া হয়, মিলিয়ে দেখুন
  • একটি শব্দ থেকে নিয়ম বের করুন: তারপর অন্য শব্দে প্রয়োগ করুন
  • সময় বাঁচান: প্রথম ও শেষ অক্ষরের shift দিয়ে options eliminate করুন
⚡ শর্টকাট ট্রিক (Shortcut Trick): শুধু প্রথম অক্ষরের কোড দেখে options eliminate করুন। যেমন CAT→DBU তে D = C+1। তাহলে DOG এর কোড E দিয়ে শুরু হবে। শুধু E দিয়ে শুরু option বাছুন।

প্র্যাকটিস প্রশ্ন (Practice Questions)

Q1. যদি PEN কে QFO লেখা হয়, তাহলে BIG কে কী লেখা হবে?
(A) CJH (B) AHF (C) CJG (D) DKH

উত্তর: Option (A) CJH — P→Q(+1), E→F(+1), N→O(+1)। B+1=C, I+1=J, G+1=H = CJH।

Q2. যদি BOOK কে YLLP লেখা হয়, তাহলে TOOL কে কী লেখা হবে?
(A) GLLM (B) GLLO (C) GOOM (D) GLLP

উত্তর: Option (A) GLLM — Opposite Letter coding (Sum=27)। T↔G, O↔L, O↔L, L↔O? Actually B(2)↔Y(25), O(15)↔L(12)... wait, 2+25=27✓, 15+12=27✓, 15+12=27✓, 11+16=27→P? Actually BOOK=YLLP: B↔Y(27), O↔L(27), O↔L(27), K↔P(27)✓. TOOL: T↔G(27), O↔L(27), O↔L(27), L↔O(27)=GLLO.

Q3. যদি WATER কে RETAW লেখা হয়, তাহলে RIVER কে কী লেখা হবে?
(A) REVIR (B) RIVIR (C) REVRI (D) RIVER

উত্তর: Option (A) REVIR — Reverse Order coding। RIVER উল্টো = REVIR।

Q4. যদি GO কে 7-15 লেখা হয়, তাহলে 3-1-20 কোন শব্দ?
(A) BAT (B) CAT (C) RAT (D) HAT

উত্তর: Option (B) CAT — Position Value coding: 3=C, 1=A, 20=T = CAT।

Q5. যদি FACE কে HCEG লেখা হয়, তাহলে BACK কে কী লেখা হবে?
(A) DCEM (B) DCCM (C) DCEM (D) DCEK

উত্তর: Option (A) DCEM — F→H(+2), A→C(+2), C→E(+2), E→G(+2)। B+2=D, A+2=C, C+2=E, K+2=M = DCEM।

Q6. যদি SUN কে RTM লেখা হয়, তাহলে MOON কে কী লেখা হবে?
(A) LNNM (B) LMOM (C) NPPQ (D) LNNM

উত্তর: Option (A) LNNM — S→R(-1), U→T(-1), N→M(-1)। M-1=L, O-1=N, O-1=N, N-1=M = LNNM।

Q7. যদি DOG কে 4-15-7 লেখা হয়, তাহলে PIG কোড কত?
(A) 16-9-7 (B) 17-10-8 (C) 15-8-6 (D) 16-10-7

উত্তর: Option (A) 16-9-7 — Position Value: P=16, I=9, G=7।

Q8. যদি MATH কে NCUI লেখা হয়, তাহলে LIFE কে কী লেখা হবে?
(A) MJGF (B) MKGF (C) MJHF (D) NJGF

উত্তর: Option (A) MJGF — M→N(+1), A→C(+2), T→U(+1)... Actually M→N(+1), A→C(+2), T→U(+1), H→I(+1). Pattern: +1,+2,+1,+1. L+1=M, I+2=K? Recheck: MATH=NCUI: M(13)→N(14)=+1, A(1)→C(3)=+2, T(20)→U(21)=+1, H(8)→I(9)=+1. LIFE: L+1=M, I+2=K, F+1=G, E+1=F = MKGF. Answer (B) MKGF।

📝 দ্রুত পুনরাবৃত্তি (Quick Revision)

  • Coding = Encode: শব্দ → কোড (নিয়ম অনুসারে পরিবর্তন)
  • Decoding = Decode: কোড → শব্দ (নিয়ম উল্টো করে)
  • সবচেয়ে কমন: +1, +2, -1, -2 Shift coding
  • Opposite Letter: Sum = 27 (A↔Z, B↔Y, C↔X...)
  • Reverse Coding: শব্দ উল্টো করে লেখা (APPLE→ELPPA)
  • Number Coding: Position Value (A=1 to Z=26)
  • দ্রুত সমাধান: প্রথম অক্ষরের shift দেখে options eliminate করুন
  • সাবধান: Variable Shift হতে পারে — প্রতিটি অক্ষর আলাদা চেক করুন
