Syllogism

ন্যায়বাক্য

ভূমিকা ও সংজ্ঞা (Introduction & Definition)

Syllogism (ন্যায়বাক্য) হল দুটি বিবৃতি (Statements) থেকে একটি সিদ্ধান্ত (Conclusion) বের করার যুক্তি পদ্ধতি। এখানে "All", "Some", "No" শব্দগুলি ব্যবহার করে বিবৃতি তৈরি করা হয় এবং Venn Diagram দিয়ে সিদ্ধান্ত যাচাই করা হয়। ANM GNM পরীক্ষায় নিয়মিত এই প্রশ্ন আসে।

Syllogism (ন্যায়বাক্য): দুই বা ততোধিক বিবৃতি (Premise) থেকে যৌক্তিক সিদ্ধান্ত (Conclusion) বের করার প্রক্রিয়া। বিবৃতি সত্য ধরে নিয়ে সিদ্ধান্ত যাচাই করতে হয়। 💡 MCQ Tip: বিবৃতি সবসময় সত্য ধরুন, সাধারণ জ্ঞান ব্যবহার করবেন না
All (সকল): "All A are B" মানে A-এর প্রতিটি সদস্য B-তে অন্তর্ভুক্ত। Venn Diagram-এ A বৃত্ত সম্পূর্ণ B বৃত্তের ভিতরে থাকে। 💡 MCQ Tip: "All A are B" থেকে "Some B are A" সবসময় সত্য
Some (কিছু): "Some A are B" মানে A-এর অন্তত কিছু সদস্য B-তেও আছে। Venn Diagram-এ দুটি বৃত্ত আংশিক overlap করে। 💡 MCQ Tip: "Some A are B" = "Some B are A" (পরস্পর সমান)
No (কোনো...না): "No A is B" মানে A এবং B-এর কোনো সদস্য সাধারণ নয়। Venn Diagram-এ দুটি বৃত্ত সম্পূর্ণ আলাদা থাকে। 💡 MCQ Tip: "No A is B" = "No B is A" (পরস্পর সমান)
  • চার ধরনের বিবৃতি: All (Universal Affirmative), No (Universal Negative), Some (Particular Affirmative), Some...not (Particular Negative)
  • Venn Diagram: সমাধানের সবচেয়ে সহজ পদ্ধতি
  • "All" থেকে "Some": All A are B → Some A are B (সত্য) এবং Some B are A (সত্য)
  • "No" থেকে "Some not": No A is B → Some A are not B (সত্য)
  • Reverse: "All A are B" মানে "All B are A" নয়!
  • বিবৃতি সত্য ধরুন: সাধারণ জ্ঞান ব্যবহার করবেন না

গুরুত্বপূর্ণ নিয়ম (Important Rules)

বিবৃতি (Statement) অবশ্যই সত্য (Definitely True) অবশ্যই মিথ্যা (Definitely False)
All A are B Some A are B ✓, Some B are A ✓ No A is B ✗
No A is B No B is A ✓, Some A are not B ✓ All A are B ✗, Some A are B ✗
Some A are B Some B are A ✓ No A is B ✗
Some A are not B — All A are B ✗ 
        Venn Diagram Patterns:
        
        1. All A are B:        2. No A is B:
           ┌────────┐             ┌───┐  ┌───┐
           │  B     │             │ A │  │ B │
           │ ┌──┐   │             │   │  │   │
           │ │A │   │             └───┘  └───┘
           │ └──┘   │           (Separate circles)
           └────────┘
        (A inside B)
        
        3. Some A are B:      4. Some A are not B:
           ┌──┐┌──┐              ┌──┐┌──┐
           │A ││ B│              │A ││ B│
           │  ├┤  │              │ x├┤  │
           │  ││  │              │  ││  │
           └──┘└──┘              └──┘└──┘
        (Overlapping)          (Part of A outside B)
⚡ শর্টকাট ট্রিক (Shortcut Trick): প্রতিটি Syllogism প্রশ্নে Venn Diagram আঁকুন! "All" = ছোট বৃত্ত বড়র ভিতরে। "Some" = দুটি বৃত্ত overlap। "No" = দুটি আলাদা বৃত্ত। Diagram থেকে Conclusion সরাসরি দেখুন।
⚡ দ্রুত নিয়ম (Quick Rule): All + All = All, All + No = No, Some + All = Some, Some + No = Some...not। বাকি combination থেকে কোনো definite conclusion বের হয় না। এই 4টি rule মনে রাখুন!

সবিস্তার উদাহরণ (Solved Examples)

📝 উদাহরণ ১ (Example 1): Statements: All cats are dogs. All dogs are animals.
Conclusions: I. All cats are animals. II. All animals are cats.
(A) Only I follows (B) Only II follows (C) Both follow (D) Neither follows
পদক্ষেপ (Steps):
Step 1: All cats ⊂ dogs, All dogs ⊂ animals → All cats ⊂ animals ✓
Step 2: Conclusion I: All cats are animals → TRUE (All + All = All)
Step 3: Conclusion II: All animals are cats → FALSE (Reverse not valid)
∴ উত্তর (Answer): Option (A) Only I follows
📝 উদাহরণ ২ (Example 2): Statements: All roses are flowers. Some flowers are red.
Conclusions: I. Some roses are red. II. Some red are flowers.
(A) Only I (B) Only II (C) Both (D) Neither
পদক্ষেপ (Steps):
Step 1: All roses ⊂ flowers, Some flowers = red
Step 2: Conclusion I: Some roses are red → NOT definite (Red part may not overlap with Roses)
Step 3: Conclusion II: Some red are flowers → TRUE ("Some flowers are red" → "Some red are flowers")
∴ উত্তর (Answer): Option (B) Only II follows
📝 উদাহরণ ৩ (Example 3): Statements: No pen is a book. All books are copies.
Conclusions: I. No pen is a copy. II. Some copies are books.
(A) Only I (B) Only II (C) Both (D) Neither
পদক্ষেপ (Steps):
Step 1: No pen = book (আলাদা), All books ⊂ copies
Step 2: Conclusion I: No pen is a copy → NOT definite (Pens could be copies through other routes)
Step 3: Conclusion II: Some copies are books → TRUE (All books are copies → Some copies are books)
∴ উত্তর (Answer): Option (B) Only II follows
📝 উদাহরণ ৪ (Example 4): Statements: Some dogs are cats. No cat is a bird.
Conclusions: I. Some dogs are not birds. II. No dog is a bird.
(A) Only I (B) Only II (C) Both (D) Neither
পদক্ষেপ (Steps):
Step 1: Some dogs = cats, No cat = bird
Step 2: Some + No = Some...not → Some dogs are not birds ✓
Step 3: Conclusion II: No dog is a bird → NOT definite
∴ উত্তর (Answer): Option (A) Only I follows
📝 উদাহরণ ৫ (Example 5): Statements: All men are strong. All strong are healthy.
Conclusions: I. All men are healthy. II. Some healthy are men.
(A) Only I (B) Only II (C) Both (D) Neither
পদক্ষেপ (Steps):
Step 1: All men ⊂ strong ⊂ healthy → All men ⊂ healthy ✓
Step 2: All men are healthy → Some healthy are men ✓ (All → Some reverse)
Step 3: Both I and II follow
∴ উত্তর (Answer): Option (C) Both follow

গুরুত্বপূর্ণ তথ্য (Important Facts)

  • All + All = All: All A are B + All B are C = All A are C
  • All + No = No: All A are B + No B is C = No A is C
  • Some + All = Some: Some A are B + All B are C = Some A are C
  • Some + No = Some...not: Some A are B + No B is C = Some A are not C
  • "Some" is Reversible: Some A are B = Some B are A
  • "No" is Reversible: No A is B = No B is A
  • "All" is NOT Reversible: All A are B ≠ All B are A
  • Venn Diagram: সবচেয়ে নির্ভুল এবং দ্রুত পদ্ধতি
⚡ শর্টকাট ট্রিক (Shortcut Trick): মনে রাখুন: "All + All = All", "All + No = No", "Some + All = Some", "Some + No = Some...not"। এই 4টি combination মনে রাখলে Venn Diagram ছাড়াও সমাধান করতে পারবেন!

প্র্যাকটিস প্রশ্ন (Practice Questions)

Q1. Statements: All apples are fruits. All fruits are food.
Conclusions: I. All apples are food. II. Some food are apples.
(A) Only I (B) Only II (C) Both (D) Neither

উত্তর: Option (C) Both — All+All=All: All apples are food ✓। All→Some reverse: Some food are apples ✓।

Q2. Statements: No car is a bus. All buses are trains.
Conclusions: I. No car is a train. II. Some trains are buses.
(A) Only I (B) Only II (C) Both (D) Neither

উত্তর: Option (B) Only II — No car is bus + All bus are train ≠ No car is train (not definite)। All buses are trains → Some trains are buses ✓।

Q3. Statements: Some men are doctors. All doctors are educated.
Conclusions: I. Some men are educated. II. All educated are doctors.
(A) Only I (B) Only II (C) Both (D) Neither

উত্তর: Option (A) Only I — Some+All=Some: Some men are educated ✓। All educated are doctors → FALSE (reverse of All)।

Q4. Statements: All books are pens. No pen is a pencil.
Conclusions: I. No book is a pencil. II. Some pens are books.
(A) Only I (B) Only II (C) Both (D) Neither

উত্তর: Option (C) Both — All+No=No: No book is pencil ✓। All books are pens → Some pens are books ✓।

Q5. Statements: Some cats are dogs. Some dogs are rats.
Conclusions: I. Some cats are rats. II. Some dogs are cats.
(A) Only I (B) Only II (C) Both (D) Neither

উত্তর: Option (B) Only II — Some+Some = No definite conclusion (I ✗)। Some cats are dogs → Some dogs are cats ✓ (reversible)।

Q6. Statements: All girls are students. No student is lazy.
Conclusions: I. No girl is lazy. II. Some lazy are students.
(A) Only I (B) Only II (C) Both (D) Neither

উত্তর: Option (A) Only I — All+No=No: No girl is lazy ✓। No student is lazy → Some lazy are students ✗ (FALSE)।

Q7. Statements: All tigers are lions. All lions are animals.
Conclusions: I. All tigers are animals. II. All animals are tigers.
(A) Only I (B) Only II (C) Both (D) Neither

উত্তর: Option (A) Only I — All+All=All: All tigers are animals ✓। All animals are tigers ✗ (reverse invalid)।

Q8. Statements: No A is B. No B is C.
Conclusions: I. No A is C. II. Some A are not C.
(A) Only I (B) Only II (C) Both (D) Neither

উত্তর: Option (D) Neither — No+No = No definite conclusion। A ও C-এর মধ্যে কোনো নিশ্চিত সম্পর্ক নেই।
